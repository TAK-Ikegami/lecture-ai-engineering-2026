## 宿題

- 取り組んだレベル：実装 
- やったこと：Quriにアシストしてもらって、会話履歴を保存して利用できるような機能を追加した。
　ベースのソースコードで使われいるgenerate_content()は１問１答の関数で、会話履歴を保存できない
　chats.create()とsend_message()を使うことにより、履歴が保持されるようにした。
　具体的には
    client.chats.create()で会話を1つ作る
    ユーザーの質問ごとにchat.send_message()を呼ぶ
    同じchatを使い続けることで、履歴が保持される
    exitまたはquitで終了する
　とした。
- 結果：uv run python -m app.ask "LoRAとは何ですか？"と入力するとこれまでどおり１問１答となる。
　uv run python -m app.ask --chatとすると連続して質問できる。2回目以降の回答は前の履歴を踏まえて回答してくれる。
